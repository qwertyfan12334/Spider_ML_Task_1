# Spider_ML_Task_1
Base Task Problem Statement –  Your task is to implement the given Neural Network model using PyTorch and train it on the Fashion - MNIST  dataset. The model should include a proper training pipeline with forward and backward propagation. During training, you must print training and validation loss/accuracy and plot them against epochs using Matplotlib. 

Applied_ML Task Problem Statement - you are expected to build a Retrieval-Augmented Generation (RAG) pipeline capable of understanding and retrieving information from multiple research papers. You will be provided with a collection of papers related to modern NLP and Large Language Models, covering topics such as Transformers, BERT, GPT, RAG, Sentence Embeddings, LoRA, and Llama. Your task is to build a system that can ingest the provided PDFs, process them, store the information efficiently, and answer user queries using retrieved context from the papers. The system should be capable of handling conceptual questions, paperspecific questions, and comparison-based queries across multiple papers.
